## 2. Technical Clause Traceability (Problem Statement 26167)

| Requirement | Implementation Summary | Evidence | Status | Limitation |
| :--- | :--- | :--- | :---: | :--- |
| **Natural Language EO VQA** | `QueryInterpreter` and multi-tier LLM/VLM parse user intent; maps to specialized GIS and vision actions. | Evaluated on RSVQA-LR (500 items, 29.40% Overall, 53.71% Presence); [`benchmark-results/RSVQA_summary.json`](benchmark-results/RSVQA_summary.json) | **VERIFIED (BOUNDED)** | Numerical counting accuracy is low (4.72%); open attributes are 0.00%; system enforces Immediate Null Policy (`confidence = null`). |
| **Multi-Sensor Fusion (Optical + SAR)** | Co-registered Sentinel-2 and Sentinel-1 processing; Lee speckle filter, $\sigma^0\text{ dB}$ calibration; CROMA 194.3M latent cross-attention. | Bengaluru scene `015_optical_sar_fusion`; [`demos/hero_02_optical_sar.png`](demos/hero_02_optical_sar.png), [`demos/hero_02_trace.png`](demos/hero_02_trace.png) | **VERIFIED** | Severe wind roughening ($>15\text{ m/s}$) can elevate water backscatter above $-18\text{ dB}$; flagged as environmental caveat. |
| **Multi-Temporal Change Detection** | Bi-temporal Sentinel-2 pair differencing; Siamese cross-attention head + deterministic NDBI/NDVI gate. | Bengaluru scene `017_bitemporal_urban_change`; CDVQA benchmark (59.00% Hybrid); [`demos/hero_03_bitemporal.png`](demos/hero_03_bitemporal.png) | **VERIFIED** | Change detection requires co-registration displacement $< 6.0\text{ px}$; aborted if orthorectification error exceeds threshold. |
| **Spatial Grounding & Coordinates** | Text-guided bounding box detection via Florence-2 LoRA; affine raster transformation to WGS-84 coordinates. | Model card [`models/model_cards/florence2_rs_lora.md`](models/model_cards/florence2_rs_lora.md); Leaflet vector overlays | **VERIFIED** | Bounding box coordinates are bounded by GSD (10m); emits `UNRESOLVED_GROUNDING` if zero targets detected. |
| **Physical Constraints & Nyquist Barrier** | Mathematical spatial resolution validation checking target size against $2 \times \text{GSD}$ sampling limit. | Scene `020_nyquist_safety`; [`demos/nyquist_abstention.png`](demos/nyquist_abstention.png); automated unit test | **VERIFIED** | Rejects queries targeting objects smaller than 20m on 10m Sentinel-2 data with `PHYSICALLY_UNRESOLVABLE`. |
| **Cross-Sensor Contradiction Arbitration** | Multi-sensor arbitration giving microwave dielectric penetration primacy over cloud-attenuated optical pixels. | Scene `015_optical_sar_fusion`; [`validation/specialist_bypass_results.md`](validation/specialist_bypass_results.md) | **VERIFIED** | Evaluated under `CROMA_LIMITED_EVIDENCE`; representation alignment cannot override calibrated backscatter decibels. |
